# Adders and Subtractors

Verilog RTL implementations and functional verification of different adder and subtractor circuits.

## Implementations

* **Half Adder**
* **Half Subtractor**
* **Full Adder**
* **Full Subtractor**
* **N-bit Full Adder**
* **N-bit Full Subtractor**
* **Combined Full Adder and Full Subtractor** in a single configurable module

## Verification

Each implementation includes a dedicated Verilog testbench to verify its functionality for different input combinations and configurations.

## Key Concepts

* Combinational Logic
* Arithmetic Circuits
* Parameterized RTL Design
* Modular Design
* Functional Verification

## Tools

* Verilog HDL
* Synopsys
* VCS , Verdi
* RTL Simulation
* Testbench-based Verification
