# Demultiplexer

Verilog RTL implementations and functional verification of different Demultiplexer configurations.

## Implementations

* **1:4 Demultiplexer**
* **1:8 Demultiplexer**

## Verification

Each implementation includes a dedicated Verilog testbench to verify correct output selection for different select-line combinations.

## Key Concepts

* Combinational Logic
* Data Routing
* RTL Design
* Functional Verification

## Tools

* Verilog HDL
* Synopsys
* VCS , Verdi
* RTL Simulation
* Testbench-based Verification
