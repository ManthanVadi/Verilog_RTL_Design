# Encoder

Verilog RTL implementations and functional verification of different Encoder configurations.

## Implementations

* **4:2 Encoder**
* **16:4 Encoder**
* **Priority Encoder**

## Verification

Each implementation includes a dedicated Verilog testbench to verify correct encoding functionality for different input combinations.

## Key Concepts

* Combinational Logic
* Data Encoding
* Priority Logic
* RTL Design
* Functional Verification

## Tools

* Verilog HDL
* Synopsys
* VCS , Verdi
* RTL Simulation
* Testbench-based Verification
