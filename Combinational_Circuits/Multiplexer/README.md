# Multiplexer

Verilog RTL implementations and functional verification of different Multiplexer configurations.

## Implementations

* **2:1 Multiplexer**
* **8:1 Multiplexer**
* **16:1 Multiplexer**
* **32:1 Multiplexer** — implemented using 8:1 Multiplexer modules

## Verification

Each implementation includes a dedicated Verilog testbench to verify the functionality and input selection for all possible select-line combinations.

## Key Concepts

* Combinational Logic
* RTL Design
* Hierarchical / Modular Design
* Functional Verification

## Tools

* Verilog HDL
* RTL Simulation
* Synopsys
* VCS , Verdi
