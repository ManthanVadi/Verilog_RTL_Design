# Combinational Circuits

This directory contains **Verilog RTL implementations and functional verification of fundamental combinational logic circuits**.

## Implementations

### 1. Adders & Subtractors

* Half Adder
* Half Subtractor
* Full Adder
* Full Subtractor
* N-bit Full Adder
* N-bit Full Subtractor
* Combined Full Adder & Full Subtractor

### 2. Multiplexers

* 2:1 Multiplexer
* 8:1 Multiplexer
* 16:1 Multiplexer
* 32:1 Multiplexer using 8:1 Multiplexer modules

### 3. Demultiplexers

* 1:4 Demultiplexer
* 1:8 Demultiplexer

### 4. Encoders

* 4:2 Encoder
* 16:4 Encoder
* Priority Encoder

## Verification

Each circuit includes a dedicated Verilog testbench for functional verification.

* Combinational Logic
* RTL Design
* Modular & Hierarchical Design
