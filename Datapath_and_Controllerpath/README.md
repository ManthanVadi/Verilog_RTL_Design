# Advanced RTL Circuits

Verilog RTL implementations of algorithm-based arithmetic circuits using **Datapath and Control Path architecture**.

## Implementations

### 1. GCD Calculator

Implemented a **Greatest Common Divisor (GCD)** calculator using an iterative algorithm.

The design is divided into:

* **Datapath** — performs the required arithmetic operations and stores intermediate values.
* **Control Path** — controls the sequence of operations using control signals and state transitions.

### 2. Multiplication with Repetition

Implemented multiplication using a **repetitive/iterative approach** instead of a direct multiplication operator.

The design uses:

* Datapath for arithmetic operations and intermediate data storage
* Control Path for controlling the iterative multiplication sequence

## Key Concepts

* Datapath and Control Path
