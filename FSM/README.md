# Finite State Machines

Verilog RTL implementations and functional verification of different **Finite State Machine (FSM)** based digital circuits and controllers.

## Implementations

### 1. Parity Checker

Implemented a **Parity Checker FSM** to detect and verify the parity of an incoming serial bit stream.

### 2. Sequence Detectors

Implemented FSM-based sequence detectors for:

* **1010**
* **01101**

The sequence detectors are designed to detect the specified bit patterns from a serial input stream.

### 3. Traffic Light Controller

Implemented an **FSM-based Traffic Light Controller** to control the sequence of traffic signals through different operating states.

The design demonstrates state-based control and timed state transitions for traffic signal management.

## Key Concepts

* Finite State Machines
* State Transition Design
* Moore / Mealy FSM Concepts
* Sequence Detection
* Sequential Control Logic
* RTL Design
* Functional Verification

## Verification

Each FSM design includes a dedicated Verilog testbench to verify state transitions and functional behavior for different input sequences and operating conditions.
