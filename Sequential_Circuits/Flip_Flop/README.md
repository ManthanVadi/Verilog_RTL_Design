# Flip-Flops

Verilog RTL implementations and functional verification of fundamental **sequential storage elements**.

## Implementations

### 1. SR Flip-Flop

Implemented an **SR (Set-Reset) Flip-Flop** with Set and Reset control inputs.

### 2. JK Flip-Flop

Implemented a **JK Flip-Flop**, including the toggle operation when both inputs are asserted.

### 3. D Flip-Flop

Implemented a **D (Data) Flip-Flop** for storing and transferring a single-bit data value on the active clock edge.

### 4. T Flip-Flop

Implemented a **T (Toggle) Flip-Flop** that maintains or toggles its state based on the T input.

## Key Concepts

* Sequential Logic
* Clocked Storage
* State Retention
* Set, Reset & Toggle Operations
* Clock Edge-Based Operation
* RTL Design
* Functional Verification

## Verification

Each Flip-Flop implementation includes a dedicated **Verilog testbench** to verify:

* Correct state transitions
* Clock-edge behavior
* Input-to-output functionality
* Reset behavior
* State retention and toggle operation where applicable

## Tools

* Verilog HDL
* Synopsys
* VCS , Verdi
* RTL Simulation
