# Latches

Verilog RTL implementation and functional verification of a basic **SR Latch**.

## Implementation

### SR Latch

Implemented an **SR (Set-Reset) Latch**, demonstrating level-sensitive sequential storage.

The design supports:

* Set operation
* Reset operation
* Hold / state retention
* Invalid input condition

## Key Concepts

* Sequential Logic
* Level-Sensitive Storage
* Set and Reset Operations
* State Retention
* RTL Design
* Functional Verification

## Verification

A dedicated Verilog testbench is included to verify the SR Latch behavior for different input conditions and state transitions.

## Tools

* Verilog HDL
* Synopsys
* VCS , Verdi
* RTL Simulation
* Testbench-based Verification
