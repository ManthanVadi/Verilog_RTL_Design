# Shift Registers

Verilog RTL implementations and functional verification of different **shift register configurations**.

## Implementations

### 1. Serial-In Serial-Out (SISO)

Implemented a **Serial-In Serial-Out (SISO) Shift Register** for serial data input and serial data output.

### 2. Serial-In Parallel-Out (SIPO)

Implemented a **Serial-In Parallel-Out (SIPO) Shift Register** for converting serial input data into parallel output data.

### 3. Parallel-In Serial-Out (PISO)

Implemented a **Parallel-In Serial-Out (PISO) Shift Register** for loading parallel data and shifting it out serially.

### 4. Parallel-In Parallel-Out (PIPO)

Implemented a **Parallel-In Parallel-Out (PIPO) Register** for parallel data loading and parallel data transfer.

## Verification

Each register implementation includes a dedicated **Verilog testbench** to verify:

* Data loading
* Shift operation
* Serial input/output
* Parallel input/output
* Clocked data transfer
